# 产品需求 — fuck-anthropic guard

[English](PRD.en.md) | **简体中文**

## 产品目标

为已经使用 Surge 的 macOS 用户提供两项清晰能力：管理可识别的 Claude 进程并查看 IPv6 设置；将可识别客户端限制到已验证的 Surge 路径。流量由 Surge 转发，Guard 不提供代理或 VPN。

## 用户需求

- 查看可识别的 Desktop、原生 CLI 和可靠追溯的后代；确认后退出所列进程，不将 Surge 列为目标。
- 只读查看物理网络的 IPv6 设置，不修改它。
- 明确启用保护后允许已验证的 Surge 专用路径；检查失败、过期或失联时撤销许可。
- 区分未启用、执行未知、阻断中和最近验证通过，不能把未知显示成安全。
- 即时切换简体中文与英文，不重启监测或改变保护状态。

## 功能要求

| 范围 | 要求 |
|---|---|
| 身份 | 官方签名或稳定的同用户父子关系；名称本身不是身份。 |
| 退出 | 确认前冻结目标；SIGTERM 前重验 PID、UID、启动时间和路径；不自动强杀。 |
| IPv6 | 只读当前 Wi-Fi／以太网服务设置，明确显示未知。 |
| 过滤 | 将可识别客户端限制到配置的 TCP 入口，检查 Surge 签名、监听者、生效规则、有时效的配置证据和出口。 |
| 生命周期 | 许可过期、控制失联或 Surge 身份变化时撤销放行，可撤销已跟踪连接。 |
| 配置 | 使用 Surge 专用端口，不修改系统代理、Surge 或路由；仅保存非秘密条件与摘要。 |
| 通知 | 自动监测中每个不安全阶段提醒一次，恢复后重新允许提醒；手动保持阻断不触发故障提醒。 |
| 语言 | 界面、对话框、状态、后续通知及手册支持双语；正式版保存选择，Preview 仅存内存。 |
| 分发 | 默认离线 Preview，生产目标仅构建；真实过滤器需要有效签名和 macOS 授权。 |

## 不在范围内

代理／VPN／SSH 转发、读取 VPS 私钥、自动修改 Surge 或自动回退、凭据清理、IPv6 开关、后台操作真实 Claude 会话，以及账号安全保证。

## 约束与验收

共享 6152 端口可能合法选择 DIRECT。严格保护要求 Surge 专用监听入口，以及固定到单个受支持 Hysteria2 节点的首条 IN-PORT 规则；客户端须显式使用该入口。经用户同意的出口探针通过 Surge 访问 api.ipify.org，不带账号数据，不回退 DIRECT。

快照不等于逐包证明。未知进程、过滤器故障、开机首包和物理网络变化需要实机验证；App、说明书和发布说明须一致呈现这些限制。

离线验收覆盖错误入口／直连／UDP、基础设施排除、用户与未知身份边界、过期、重放及身份变化。Preview、主程序及过滤器须能独立构建，Preview 不得链接生产后端。在重要会话之外进行隔离实测，详见[验证状态](FEATURE-STATUS.zh-CN.md)。

通知权限、专注模式和 macOS 设置可能抑制横幅。提醒表示许可已撤销，不把执行未知说成阻断已确认。已投递通知保留原语言；系统对话框遵循 macOS 设置。

## 本地 UI 修订（2026-09-29）

首屏显示状态、专用入口和固定策略，放行/拒绝/未知归属计数独立展示。客户端、网络和诊断分为三个标签页；危险操作保留确认。界面只能反映已确认的执行与路径状态，不能把等待或失联显示为绿色。深浅色和双语切换不得改变保护状态。

## 连接记录与界面（0.4.1）

暖白纸色、陶土色重点、衬线标题与原创 G 盾牌图标。默认深色：炭灰背景、暖灰面板、米白文字、陶土橙重点；顶部外观按钮可切换浅色。

“连接记录”显示已识别客户端的时间、PID、目标、协议、判定与原因；全部/允许/拒绝筛选和首页计数可联动。允许表示通过入口与许可检查，不代表最终网站请求成功，后续仍可能撤销。拒绝计数包含新连接拒绝与已有连接撤销，不一定是唯一连接数。旧端口匹配计数不再作为允许总数。

最近80条仅保留在过滤器内存，重启扩展后清空；不存聊天、请求正文、URL路径或凭据。未知归属只计数，不记录其他应用。失去同步会明确标示，历史不代表当前许可。升级前的明细无法恢复。

“工作原理”：Claude → Guard系统过滤 → 本机Surge专用入口 → 代理节点 → 网站。Guard不提供VPN、订阅或SSH；Surge负责传输。127.0.0.1:6154是代理入口，不是最终网站。本版升级过滤扩展的记录能力，保留既有路由条件和许可机制。

## 0.4.2 使用体验

“阻断Claude连接…”会先确认影响，取消不改变许可；“恢复连接检查…”重新验证后才允许连接。设置页按实际状态显示“保护已启用”或恢复入口；保护开启/状态不明时只能查看入口。“重新检查”会重试过滤器控制连接，普通客户端刷新只更新进程列表。

连接记录支持按进程、PID、目标搜索，清除搜索恢复当前类别；点击表头排序，选择一条后查看详情或复制。详情含完整时间、签名身份、目标及可用的触发原因。未记录的原因明确显示缺失，不推断旧事件的根因。归属未知可点击查看解释，不是泄漏次数。

计数入口为原生按钮；拒绝文字提高对比度。外观选择在正式App中保存。小窗口可滚动查看全部内容。

## 0.4.3 表单修复
配置输入校验在关闭弹窗前完成，错误保留字段并定位对应输入；不改变过滤器或路径授权逻辑。
